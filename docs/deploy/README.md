# Deploy guide

Steps to publish digiworlds.store on Cloudflare Pages.

1. [cloudflare-pages.md](cloudflare-pages.md): create the Pages project, add the domains, redirects, analytics, first-deploy checks.
2. [dns.md](dns.md): what the DNS records look like today, what changes, what must never change.
3. [editing.md](editing.md): change copy and values, redeploy, and the checklist before the Polar review.

Do the steps in order. Never touch the email records (see dns.md).
