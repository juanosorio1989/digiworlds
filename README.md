# digiworlds.store

Bilingual (Spanish and English) static sales site for digiworlds, built with Astro.

```
npm install
npm run dev      # local dev server
npm run check    # type check, unit tests, build and dist checks
```

Docs: [docs/deploy/](docs/deploy/README.md) (Cloudflare Pages, DNS, editing). Design and plan: `docs/superpowers/`.
